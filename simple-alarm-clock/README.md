# simple-alarm-clock

シンプルな UI のブラウザ用アラームアプリです。ビルド不要、HTML / CSS / JavaScript のみで動作します。

## 機能

- 現在時刻の表示
- アラームの追加（時刻 + 任意のラベル）
- アラームの有効/無効切り替え
- アラームの削除
- 設定時刻になるとアラーム音（ビープ音）が鳴り、停止ボタンで止められる
- アラームはブラウザの localStorage に保存され、再読み込み後も保持される

## 使い方

`index.html` をブラウザで開くだけで使えます。

```
open index.html
```

またはローカルサーバーで:

```
python3 -m http.server 8000
```

にアクセスしてください。

## ファイル構成

- `index.html` — 画面構造
- `style.css` — スタイル
- `app.js` — アラームのロジック
